
1️⃣ JDBC Basics

JDBC is a Java API that allows Java programs to interact with databases.

Key Components
Component	Description
Driver	Connects Java to a specific database (e.g., MySQL Connector/J)
Connection	Represents a session with the database
Statement	Executes SQL queries (use for simple queries)
PreparedStatement	Executes parameterized queries, safer and faster
ResultSet	Stores results from a query (SELECT)
SQLException	Handles database errors


JDBC Project – E-Commerce Example
Project Overview
This project demonstrates Java JDBC (Java Database Connectivity) with CRUD operations using a sample E-Commerce database.

You will learn how to:
Connect Java applications to a MySQL database.
Perform Create, Read, Update, Delete (CRUD) operations.
Use PreparedStatement for safe SQL queries.
Handle timestamps, auto-increment, and foreign keys.
